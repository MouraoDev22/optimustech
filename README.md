## 💻 Sobre o projeto

Este projeto consiste no desenvolvimento de uma landing page responsiva para a **OptimusTech**, uma empresa fictícia de tecnologia. O foco principal foi a prática de estruturação semântica e estilização moderna.

---

## 🛠 Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **Git & GitHub**

## 🚀 Como executar

### Executar localmente

1. Clone este repositório
2. Abra a pasta do projeto
3. Execute o arquivo **index.html** no navegador

### Executar online

Acesse diretamente pelo GitHub Pages
