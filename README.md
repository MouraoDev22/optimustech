## 💻 Sobre o projeto

Este projeto consiste no desenvolvimento de uma landing page responsiva para a **OptimusTech**, uma empresa fictícia de tecnologia. O foco principal foi a prática de estruturação semântica e estilização moderna.

## 🛠 Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **Git & GitHub**

## 🚀 Como executar

Para visualizar o projeto:

1. Clone este repositório.
2. Abra o arquivo `index.html` no seu navegador de preferência.

ou

Acesse o link da página no GitHub Pages: mouraodev22.github.io/optimustech/

## 🎨 Design

O layout seguiu as especificações do design system proposto no desafio, garantindo fidelidade visual e adaptação para diferentes tamanhos de tela.
